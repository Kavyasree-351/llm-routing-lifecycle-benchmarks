# LLM Routing Lifecycle Benchmarks

A CPU research-engineering harness for comparing LLM routing quality, historical inference costs, feedback acquisition and deployment payback using the public RouterBench cache.

Includes strong simple routing controls, lifecycle cost accounting, multiple seeds, paired uncertainty, reproducible splits, gate decisions and retained negative findings. **Exploratory research; no new-method or present-day price/latency claim.**

Read [ASSESSMENT.md](ASSESSMENT.md), [PROTOCOL.md](PROTOCOL.md) and [ATTEMPTS.md](ATTEMPTS.md).

## Standalone quickstart

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe run_checks.py
.\.venv\Scripts\python.exe fetch_data.py
.\.venv\Scripts\python.exe study.py --stage pilot
.\.venv\Scripts\python.exe report.py
```

Run from this repository root; Linux/macOS use `.venv/bin/python`. The ignored cache is `work/lifecycle-routing/routerbench_0shot.pkl`. Download is about 100 MB; it is not included in Git. Source revision and SHA256 are pinned in source.json, and the reader verifies the checksum before allowlisted deserialization. No paid API calls, model keys or private data are required. Use `--data PATH` on study.py to choose a different cache.

`run_checks.py` runs bounded tests without downloading data or opening evaluation pools. Saved outcomes, historical alternatives, CSV tables and PNG/PDF plots are in results. These are cached historical outcomes, not current serving/energy measurements. Fresh/final runs remain gated. Historical corrected attempts are retained for transparency rather than claimed to be generated by the current implementation.
